# Whisper

## Definition

Whisper is a family of speech recognition models used to convert spoken audio into text. Developers commonly use Whisper-style APIs for transcription, translation, captioning, and searchable audio archives.

## Context and Usage

In developer tools, Whisper usually sits behind a CLI, web app, or background worker. The application prepares the audio, sends it to a transcription provider, receives text, and stores that text for search, editing, summarization, or accessibility workflows.
